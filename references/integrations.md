# 客户端接入：同一协议，分别验收

本文给出公开文档支持的入口，不表示已在使用者的客户端中验证。官方来源与核对日期见 [sources.md](sources.md)。具体版本、工作模式和权限不同，发现不一致先核实再配置。

## 1. 共用的短入口

复制到客户端已确认支持的规则位置。将路径替换为**本机真实绝对路径**，不要把尖括号占位符原样保存；初始化器生成的“接入说明.md”会给出本机路径。

```text
个人知识库规则入口：<知识库绝对路径>/90-智能体记忆/记忆规则.md
开始本次任务先读取该规则，再按需读取 MEMORY.md、TODO.md 和相关项目记忆。
只在用户授权且宿主允许的范围内读写；不能访问时明确说明，不声称已经读取或保存。
任务结束按规则提炼写回并报告修改文件。遵守单一整理者/待合并提案约定，不用缓存覆盖精选记忆。
```

短入口负责引导读取，不复制全部记忆。vault 内的 `AGENTS.md` 只对实际加载它的环境有用，放在本地文件夹里不会使所有智能体自动发现它。

## 2. WorkBuddy 桌面端

### 技能安装

根据官方“技能”文档，可在技能界面“添加技能 → 上传技能”导入本地包。核对当前版本界面，导入后在已安装列表确认开启；技能被发现不等于知识库已接入。包内 `SKILL.md` 和相对资源须完整保留。若不接受当前 ZIP 层级，先解压，按界面要求选技能文件夹；不要在不明目录里盲试覆盖。

### 优先：限定范围的项目接入

若该版本支持本地项目工作目录，选择 vault 为工作目录，并确认当前模式确实加载 `AGENTS.md`。官方项目文档列出与 `AGENTS.md` 的兼容，但不能据此推断所有办公任务模式都会加载。

若项目已有规则，备份后加入短入口，不替换正文。官方代码开发项目配置列出 `.codebuddy/rules/`、`.codebuddy/skills/`、`.codebuddy/CODEBUDDY.md`；这些是对应项目/模式的入口，不当作所有 WorkBuddy 模式的通用路径。不要把“支持代码开发项目规则”扩写为“每个聊天都自动读”。

### 需要跨项目生效

在当前客户端的设置或官方文档中确认“全局/用户规则”真实入口、适用模式和格式。说明影响范围，获得对应配置修改授权，备份后只加入短指针；如有覆盖规则或停用状态，先诊断。没有证据时不创建猜测路径，也不写入或软链替换 `~/.workbuddy/MEMORY.md`。

### 可靠降级

无法确认持久入口时，每次新任务显式发送“请先读取【真实规则文件路径】并按其要求接续工作”，并授权读取目录。标注“手动接入”，不要包装成自动接入。如果只能上传附件，使用经过授权的精简、脱敏上下文包，标注它是某日快照而非实时知识库；回写通过人工检查的提案完成。

### 内置记忆与删除

WorkBuddy 官方“记忆”文档描述了独立的提取、查看、编辑、删除和关闭机制。它不是 vault 自动同步接口，不保证与本方案一致。发生偏好冲突时回到用户确认和权威来源，必要时由用户在产品设置中纠正。删除 vault 内容不代表已删除产品内置记忆或服务商保留的数据。

## 3. Codex

### 安装技能

当前官方技能文档列出用户目录 `$HOME/.agents/skills/` 及仓库内 `.agents/skills/`。将整个技能文件夹复制到支持的位置，保持文件夹名 `obsidian-agent-brain`，然后在新会话里确认发现情况，使用 `$obsidian-agent-brain` 调用。已有相同名称时先检查，不覆盖。

部分环境另有配置或兼容目录（例如已有的 `~/.codex/skills`）；尊重已验证的本机配置，不把特定安装的兼容行为当成通用规范，不重复安装同名技能制造冲突。

### 记忆入口

项目内使用该项目实际加载的 `AGENTS.md` 加短入口；全局默认位于 Codex home（通常 `~/.codex`，也可能由 `CODEX_HOME` 改变）。先确认该路径及 `AGENTS.override.md` 的优先级，备份后合并到实际有效的规则文件，不为此删除覆盖文件或修改其他偏好。

全局指针只扩大“提示读取”的范围，不扩大沙箱权限；在其他项目中读取 vault 可能仍需用户授予访问。新会话从不同工作目录测试，确认来源路径和范围。不要把创建项目规则称为全局接入。

## 4. 其他智能体、远程环境与手机

按四项能力适配：能否安装/加载技能、能否读本机文件、能否获得持久规则、能否授权写回。入口文件名由各产品定义，不预设都认 `AGENTS.md`。

远程容器、云端任务、手机或小程序的文件系统通常与桌面不同，须实际核对；缺少访问能力时用获准的脱敏快照或受控连接器。增加 MCP、同步服务、端口或网络暴露是独立方案，需要新的范围与授权，不在基础建库时顺带开启。

“同一份数据”限能访问同一权威位置的客户端；多设备路径和同步冲突未处理时，不宣称实时全设备共享。

## 5. 必填接入记录

在 vault 的“接入说明.md”记录客户端/版本、模式、规则入口、可读写范围、写回角色、最后实测日期、实测证据与状态。允许状态：`未接入`、`手动接入已测`、`指定项目自动入口已测`、`跨项目入口已测`、`受限/失败`。

不得只凭“已安装”“设置已保存”或客户端自述升级状态；按 [acceptance.md](acceptance.md) 用实际文件和新会话核验。
