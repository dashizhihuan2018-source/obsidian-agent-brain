# 使用指南

## 第一次使用

1. 在 Obsidian 的仓库管理界面选择“打开文件夹为仓库”，选本目录。
2. 打开 [[首页]]，依次试点收件箱、项目索引和待办。
3. 在目标智能体中安装技能并核对规则入口；详见 [[90-智能体记忆/接入说明]]。
4. 指定一个“记忆整理者”，确定其读写范围。其他智能体只提交待合并提案。
5. 用没有隐私的演示内容做首次写入、全新会话读取和状态更新测试；完成之前不标记为自动接入。

## 一天怎么工作

早上：说“读取相关知识库，今天有什么要做”，从已有待办选择任务。

工作中：说“开始一个项目……”或“继续上次的项目”，先恢复上下文；遇到想法说“记一下……”，资料先进入收件箱，不急着全盘分类。

完成任务：说“本次收尾”，提炼有价值的结果、决定和下一步；检查智能体报告实际修改的文件。

每周：主动说“每周复盘”，处理收件箱、核对项目、更新过期待办；需要归档时先确认。此方案不会自行安排后台定时任务。

## 常用指令

| 你说 | 预期动作 |
| --- | --- |
| 记一下…… | 分类保存；不确定先放收件箱 |
| 整理这些资料 | 保留原件、来源，提炼摘要并关联主题 |
| 开始一个项目…… | 建立项目概览、目标与下一步 |
| 继续上次的项目 | 读取项目记忆，说明进度与阻塞 |
| 今天有什么要做 | 从已有待办和活跃项目提出建议 |
| 以前研究过吗 | 检索已有笔记，指出文件和日期 |
| 本次收尾 | 分层更新项目、待办、每日摘要和必要长期记忆 |
| 忘记这条信息 | 按获准范围清理，并说明内置记忆/备份边界 |

## 内容放在哪里

- 临时想法在 `01-收件箱`。
- 有结束条件的任务在 `02-项目`，持续职责在 `03-长期领域`。
- 原始材料及出处在 `04-参考资料`，自己的理解与方法在 `05-知识卡片`。
- 当天摘要在 `06-每日记录`，不活跃内容经确认放 `07-归档`。
- 精简长期记忆、待办和接入状态在 `90-智能体记忆`。
- 新增内容可参考 `99-模板`，无需装插件即可复制使用。

模板入口：[[99-模板/项目模板]]、[[99-模板/资料模板]]、[[99-模板/知识卡片模板]]、[[99-模板/每日记录模板]]、[[99-模板/决策记录模板]]、[[99-模板/交接记录模板]]、[[99-模板/周复盘模板]]。模板不代表任务已完成、决定已批准或交接已被接受。

## 隐私与备份

不存密码、API Key、Token 或身份证号。公司资料和他人信息须先获授权。云端智能体读取本地文件时，内容可能发送给模型服务商；本地文件夹不等于完全离线。

当前未启用云同步、远程端口或自动备份。先选择独立、受保护的备份位置，保留版本化副本；敏感内容采用你认可的加密方案。同步不是备份，Git 忽略规则不是加密。

恢复时把备份复制到一个不同路径，用 Obsidian 打开副本检查，不覆盖当前库。未经当次授权，不把知识库上传 GitHub、网盘或公开网站。

## 能力边界与排查

- 不记得：确认实际规则入口、技能开启状态、目录权限，并在全新会话复测。
- 记忆冲突：先看权威文件和来源，不能只以日期新旧判断。
- 路径变动：更新客户端指针与接入说明，多设备分别维护本机路径。
- 无文件权限：改用获准的脱敏快照，明确它不是实时同步。
- 多个智能体：一个整理者修改精选记忆，其他人向待合并目录提交唯一提案。
- 删除笔记：不等于删除客户端内置记忆、云端保留数据或备份。

本指南是初始模板；实际接入范围和验收结果以 [[90-智能体记忆/接入说明]] 为准。
